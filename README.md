# Space Trucking Sim (working title)

A browser game about an independent privateer. Trade cargo between locations, build a ship from a hull and modules, hunt pirates or become a pirate. A career has 730 game days and ends with a score and a title. The visuals are animated ASCII.

**Status:** Scoped. No code yet.
